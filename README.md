This repository contains the projects I developed during my Artificial Intelligence Internship at CODSOFT, where I worked on multiple AI-based applications to strengthen my understanding of core Artificial Intelligence concepts through practical implementation. The projects include a Rule-Based Chatbot, a Tic-Tac-Toe AI, and a Recommendation System, each designed to demonstrate different foundational areas of AI such as Natural Language Processing, Game Theory, Search Algorithms, and Personalization Techniques.

The chatbot project focuses on conversational logic using predefined rules and pattern matching to simulate user interaction. The Tic-Tac-Toe AI project demonstrates strategic decision-making using the Minimax algorithm, ensuring optimal moves against a human opponent. The recommendation system showcases how personalized suggestions can be generated using user preference data through filtering techniques.

Across these projects, I applied Python programming, logical problem-solving, algorithmic thinking, and structured design principles. This internship experience allowed me to bridge theoretical knowledge with real-world application development, helping me understand how intelligent systems analyze input, evaluate possibilities, and generate meaningful outputs. Overall, these projects represent my hands-on learning journey in Artificial Intelligence and highlight my ability to design, implement, and test practical AI solutions.
